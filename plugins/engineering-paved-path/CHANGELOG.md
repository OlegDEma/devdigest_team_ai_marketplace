# Changelog

All notable changes to this plugin are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the plugin uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.1.0] - 2026-10-26

### Added

- `drizzle-orm-patterns` skill: Drizzle ORM schema definition, relations, queries, joins and aggregations, transactions, Drizzle Kit migrations, and common patterns (soft delete, upsert, batching, full-text search, audit trails), with worked examples.
- `postgresql-table-design` skill: PostgreSQL schema design rules covering data types, constraints, indexing, JSONB, partitioning, upsert-friendly design, safe schema evolution and common gotchas.

## [1.0.0] - 2026-10-26

### Added

- `architecture` skill: stack-neutral layering rules (A1–A7 backend/core, F1–F9 frontend) that work as design guidance and as review criteria, with a rule catalogue, a review checklist with `path:line` evidence format, an example layer map, and frontend organization references. The project's layer map is an input.
- `react-best-practices` skill: React component, state, hooks and data-fetching rules with severity tags and examples.
- `next-best-practices` skill: Next.js App Router conventions, RSC boundaries, data patterns, metadata, error handling, route handlers, images, fonts, bundling and self-hosting.
- `fastify-best-practices` skill: Fastify plugins, routes, schemas, hooks, auth, testing, performance and deployment rules.
- `react-testing-library` skill: user-flow-oriented React Testing Library + Vitest guide with MSW mocking.
- `security` skill: OWASP Top 10:2025 review and implementation guidance with checklists and unsafe/safe examples.
- `typescript-expert` skill: advanced TypeScript types, tsconfig, performance and migration guidance, with a diagnostic script.
- `zod` skill: 43 Zod rules across schema definition, parsing, inference, errors, objects, composition, refinements and performance.
- `mermaid-diagram` skill: Mermaid diagram selection and templates for flowcharts, sequences, ER, state and more.
